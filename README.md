## 📚 Topics Covered

### 1. Lists

The list section covers creating, modifying, and accessing Python lists.

Topics practiced:

* List creation
* `append()`
* `insert()`
* `remove()`
* `pop()`
* `extend()`
* Sorting in descending order
* `max()`
* `min()`
* `sum()`
* List indexing
* List slicing
* Reversing a list

The assignment specifically uses an age list and a name list to demonstrate these operations.

---

### 2. Dictionaries

The dictionary section focuses on storing student names and marks using key-value pairs.

Topics practiced:

* Creating a dictionary
* Accessing values
* Adding a new student
* Updating an existing student's mark
* `keys()`
* `values()`
* `items()`

The assignment requires creating a `student_marks` dictionary containing five students and their marks.

---

### 3. Sets

The set section demonstrates how Python sets handle unique values and perform set operations.

Topics practiced:

* Creating a set
* Understanding duplicate removal
* Understanding why set elements cannot be accessed using indexes
* Union
* Intersection

The assignment also compares two sets and finds their union and intersection.

---

### 4. Conditional Statements

The final section contains a **Performance Category Program** using:

* `if`
* `elif`
* `else`

The user enters a score between **0 and 10**, and the program categorizes the performance as:

| Score          | Category      |
| -------------- | ------------- |
| Greater than 7 | Above Average |
| 4 to 7         | Average       |
| Less than 4    | Below Average |

These ranges are specified in the assignment.

Example:

```text
Enter your score (0 to 10): 7
Average: Good effort! Keep practicing, there's room for improvement.
```

This follows the sample output provided in the assignment.
